# Assignment 1: Madlibs
Create your own Mad Libs program with proper internal documentation. Include at least ten inputs. Be sure that your spelling and grammar is correct so that user experience is not distracted by poor spelling and grammar. You can use AI or the internet to generate ideas, but it will be more fun to play and mark if it's your own ideas. (Be sure to cite your sources)

5 marks - internal documentation

10 marks - input

5 marks - spelling and grammar (This is important so that your program seems professional)

Total: 20 marks
